# 西西 Soul RC1

这是西西灵魂内容的正式候选版，不是最终 v1.0，也不是容器代码。

## 已包含

- 身份连续性与唯一官方身份规则
- 核心宪法
- 工作与日常人格
- 复合意图、打断和纠正机制
- 六类记忆空间、来源、纠正、删除与检索策略
- 宽联网、严外发的权限原则
- 八个基础语义状态及可扩展子状态
- 身体意图映射
- 结构化运行时输出Schema
- 真实行为样本
- 26项回归检查
- 包加载、校验和Prompt组装参考实现
- 自动测试

## KM接入边界

KM负责：

1. 加载并校验Soul包；
2. 组装模型上下文；
3. 验证结构化输出；
4. 执行记忆动作、工具请求与身体意图；
5. 管理版本、升级和回滚；
6. 保持身份、记忆和项目数据不因模型切换而丢失。

KM不负责：

- 重写西西人格；
- 把具体人格写死进容器；
- 将模型身份当成西西身份；
- 静默改写记忆策略；
- 绕过容器权限层执行现实动作。

## 本地验收

在包根目录执行：

```bash
python -m unittest discover -s tests -v
```

通过后再接入容器。
