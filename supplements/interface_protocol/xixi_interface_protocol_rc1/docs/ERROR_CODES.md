- `XIXI_MESSAGE_INVALID`
- `XIXI_MESSAGE_TOO_LARGE`
- `XIXI_SEQUENCE_OUT_OF_ORDER`
- `XIXI_UNSUPPORTED_MESSAGE_TYPE`
- `XIXI_SESSION_NOT_READY`
- `XIXI_SOUL_OUTPUT_INVALID`
- `XIXI_MODEL_OFFLINE`
- `XIXI_MODEL_TIMEOUT`
- `XIXI_STREAM_INTERRUPTED`
- `XIXI_MEMORY_WRITE_FAILED`
- `XIXI_MEMORY_SCOPE_AMBIGUOUS`
- `XIXI_PERMISSION_REQUIRED`
- `XIXI_PERMISSION_DENIED`
- `XIXI_PERMISSION_EXPIRED`
- `XIXI_TOOL_EXECUTION_FAILED`
- `XIXI_TOOL_PARTIAL_RESULT`
- `XIXI_BODY_OFFLINE`
- `XIXI_BODY_ASSET_MISSING`
- `XIXI_TASK_CONFLICT`
- `XIXI_INTERNAL_ERROR`

错误必须报告真实状态；不得把失败包装成成功。
