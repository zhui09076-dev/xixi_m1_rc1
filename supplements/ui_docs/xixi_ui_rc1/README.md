# 西西 UI RC1

这是西西桌面交互的正式候选版，不是通用后台模板，也不包含人物或场景资产。

## 已完成

- 安静陪伴、对话、工作、权限确认四种桌面状态
- 默认收起的小型玻璃应用库
- 对话、快速记录、待办、项目、模型、设置组件
- 可中断的对话交互
- 私人数据外发确认界面
- 16:9、21:9、32:9布局
- 1920×1080、3440×1440、5120×1440预览
- SVG图标、主题Token、组件契约和布局数据
- 无外部依赖的交互原型
- 自动文件检查、JavaScript语法检查和浏览器渲染检查

## 使用

直接打开：

`index.html`

也可以通过查询参数切换预览：

- `index.html?mode=quiet`
- `index.html?mode=chat`
- `index.html?mode=work`
- `index.html?mode=permission`

## 设计边界

- 人物和场景由Body内容包提供，本包不伪造正式身体资产。
- 中央区域保留人物安全区，UI不得长期遮挡脸部。
- 应用库默认收起，日常状态不出现大型仪表盘。
- 当前是RC1；需要接入真实容器并验证Qt/Electron实际窗口行为后才能冻结v1.0。
