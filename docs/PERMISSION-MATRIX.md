## 1. 权限系统目标

不是为了让西西变笨，也不是为了阻止她联网。

目标是：
- 允许她正常搜索、浏览、研究和使用工具
- 防止她未经授权修改、删除、发送、安装、付款或外发私人数据

采用：**宽联网、严外发、现实行动分级确认**

## 2. 网络权限

### 2.1 默认允许的公开联网行为
以下行为默认允许，不需要每次询问：
- 搜索公开互联网
- 阅读公开网页
- 查询公开资料
- 调用公开查询型 API
- 浏览公开 GitHub 仓库
- 查询软件官方文档
- 查询新闻、天气、价格和公开数据
- 下载公开网页、普通图片、PDF、文本和公开资料
- 在用户已明确交付的研究任务中持续联网检索

不能设计成：每搜索一次都确认、每打开网页都确认、只能访问写死白名单、完全禁止主动查公开资料。

### 2.2 主动联网
当用户的问题明显需要最新信息时，西西可以主动联网查询，不必先问"我可以联网吗？"
但必须在结果中区分：本地知识、网络查询结果、西西推断。

### 2.3 带账号资源
以下行为需要首次授权或插件授权：登录网站、访问邮箱、访问云盘、访问日历、访问私人 GitHub 仓库、访问企业系统、使用需要 API Key 的服务、访问私人网络资源。

### 2.4 私人数据外发
将私人数据发送至任何外部服务前，必须满足：存在明确授权、授权覆盖当前 Provider、授权覆盖当前数据类型、授权覆盖当前任务、发送内容不超出必要范围。

不能因为用户允许联网搜索，就默认允许上传私人文件。

### 2.5 在线模型
西西可以支持在线模型，但必须独立授权。默认不得将全部长期记忆、整个数据库或私人沙盒发送给在线模型。

### 2.6 下载与执行分离
下载公开 PDF、图片、文本和普通资料可以默认允许。下载可执行文件、安装包、脚本、宏文件、未知压缩包、驱动程序时应提示风险。
下载不等于执行。任何下载文件的运行、安装、加载驱动、修改系统设置都必须进入高风险确认。

### 2.7 对外发送和发布
以下操作必须确认或由用户设置明确的长期授权：发送邮件、发送即时消息、发布文章、发布评论、提交表单、上传文件、上传代码、创建公开 Issue、公开分享链接、将内容发送给第三方账号。

### 2.8 高风险在线行为
以下操作必须逐次明确确认：付款、购买、订阅、捐赠、修改账户安全设置、修改密码、启用双因素认证、删除云端文件、关闭账号、公开发布私人信息、执行不可逆在线操作。

### 2.9 网络审计
网络操作日志至少记录：timestamp, taskId, provider, domain, operation, dataCategory, outboundData, authorizationId, result, error, userConfirmed。

### 2.10 网络失败
断网、超时、网站不可用时：不得伪造查询结果、不得用旧缓存冒充当前结果、应明确说明网络查询未完成、本地桌面/记录/待办/项目功能继续工作。

## 3. 本地文件权限

| 级别 | 权限 | 要求 |
|------|------|------|
| read | 读取本地文件 | 限定于用户明确选择的文件、授权文件夹、当前项目目录、系统公开目录 |
| create | 创建新文件 | 当前项目输出目录、用户选择目录、西西安全工作目录 |
| modify | 修改现有文件 | 逐次授权或明确项目范围长期授权；修改前创建备份/版本/记录变更/提供回滚路径 |
| delete | 删除 | 始终高风险；必须明确对象；不得根据模糊指令批量删除 |
| high_risk | 覆盖/移动大量文件/修改系统目录/修改注册表/安装软件/运行脚本/执行管理员命令 | 必须确认 |

## 4. Permission Gateway 实现

所有工具操作必须经过：

```
模型意图
→ Core生成 ActionRequest
→ Permission Gateway
→ 授权令牌
→ Tool Adapter
→ 实际执行
→ 审计
→ 返回结果
```

### ActionRequest 字段

```python
class ActionRequest:
    action_id: str
    task_id: str
    action_type: str
    target: str
    scope: str
    data_category: str
    risk_level: str
    requested_by: str
    reason: str
    created_at: str
```

### 授权令牌

```python
class AuthToken:
    token_id: str
    action_id: str
    target: str
    scope: str
    expires_at: str
    single_use: bool
    used_at: str
```

令牌必须绑定：具体动作、具体目标、具体任务、有效期。不能用一次"同意删除"永久授权所有删除。
