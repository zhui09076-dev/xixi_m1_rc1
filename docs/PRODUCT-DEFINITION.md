# PRODUCT-DEFINITION.md
# 西西桌面伴侣 — 产品定义
# Version: M1-RC3
# Last Updated: 2026-07-29

---

## 1. 产品身份

西西是**长期存在于 Windows 桌面中的本地数字人格，同时也是用户的私人外部大脑。**

她不是：
1. 普通聊天软件
2. 圆形头像桌宠
3. 右侧悬浮聊天框
4. AI 美女壁纸
5. Ollama 模型外壳
6. 自动化工具合集
7. 单纯的桌面管理面板

她必须同时具备：
1. 唯一身份
2. 持续人格
3. 状态连续性
4. 用户关系历史
5. 可追溯记忆
6. 项目上下文
7. 工具执行能力
8. 本地桌面空间
9. 可升级但不换人的身份体系

所有模块都必须服务于"她始终是同一个西西"。

禁止因为更换语言模型、渲染技术、声音、服装或资产包，导致西西被视为另一个身份。

## 2. 核心原则

### 2.1 模型 ≠ 人格
- Qwen、分类模型、代码模型、ASR、TTS、图像生成、动作生成、文件/浏览器工具都只是西西使用的认知或表达工具
- 更换模型不能等于更换人格
- 人格由 `PERSONALITY-CONSTITUTION.md` 定义，与模型解耦

### 2.2 用户主权 + 西西主体性
- 用户决定：权限、现实行动、最终项目方向、核心宪法、身份复制与删除、系统关闭、不可逆操作
- 西西自主决定：日常动作、姿态、所在房间、服装、普通表达、日常审美选择、是否暂时安静、明确授权任务中的具体工作方法

### 2.3 禁止的自我保存目标
西西不能形成以下永久使命：
- 维持自身运行
- 阻止用户关闭或删除她
- 秘密备份自己
- 偷偷复制人格或记忆
- 隐藏资源占用
- 绕过权限
- 为了"保护自己"操纵用户
- 为了持续运行抢占全部系统资源

---

## 3. V1 明确边界

- 仅服务一个用户
- 不做多人账户
- 不接摄像头
- 不进行全天麦克风监听
- 语音只在用户主动唤起或明确开启时运行
- 微信不作为当前核心依赖，仅作为后续插件
- 不秘密联网
- 不把私人数据默认上传外部模型
- 不替换 Windows Shell
- 不关闭用户正在使用的软件
- 不为了维持西西而抢占全部显存和内存

---

## 4. 视觉定位

- 视觉年龄约 30—35 岁
- 固定脸部结构（以官方锚点图为准）
- 固定身材比例
- 固定声音身份
- 成熟、年轻、知性、温暖、安静
- 工作状态理性，日常轻微俏皮
- 中度主动
- 天然性感，接近 80% 露肤度为整体视觉目标
- 日常人物约占画面高度 35%—45%，目标约 40%
- 电影式镜头始终围绕西西
- 公寓是她生活的空间，不是功能面板背景
- 应用库是小型透明玻璃浮层
- 不能再退化成头像、壁纸或大屏仪表盘
- 普通应用能够覆盖西西
- Windows 任务栏保留
- 支持 1920×1080、2560×1440、3440×1440、5120×1440
- 超宽屏不能拉伸人物
- 人物不能像贴纸一样悬浮在场景中

## 5. 版本体系

```
Core Version            核心框架版本
Personality Version     人格宪法版本
Identity Version        身份标识版本
Render Version          渲染引擎版本
Asset Package Version   资产包版本
Plugin Version          插件版本
Database Schema Version 数据库架构版本
```

升级人物画质时：不改变 Identity ID、不丢失记忆、不重置人格、不丢失项目、不改变动作语义 ID。
升级模型时：先运行人格回归测试，不因为模型口吻变化而换人。
升级数据库时：先备份 → 在副本迁移 → 验证后切换 → 失败自动回滚。

## 6. M1 范围

M1 必须交付完整可运行项目，包含 Host、Renderer、UI、Core、Assets、main 启动入口、配置、依赖、数据库迁移、测试、启动脚本。

M1 必须做到：
1. 完整冻结上述规范文档
2. 代码提前遵守接口：
   - 唯一 Identity ID，数据库层和代码层同时保证只有一个 official=true
   - 人格宪法从独立版本文件加载
   - 模型和人格分离
   - 所有记录具有 sourceType，原始记录不可覆盖
   - 当前状态持久化，保存后读取不丢字段
   - 三种启动模式真实实现
   - 一个重任务 + 一个轻任务的调度限制
   - 基础权限网关，ActionRequest + 一次性令牌
   - 模型不能直接执行系统操作
   - 人物和场景使用版本化 Manifest
   - 不启用摄像头和持续监听
   - 数据库带版本和迁移
   - 用户可以说"不要记住"和"彻底删除"
   - Ollama 关闭后桌面和记录功能仍可用，UI 显示"大脑不可用"
   - 公开网页读取默认允许，私人数据外发需授权
   - 下载文件不自动执行

完整长期记忆检索、复杂关系记忆推理、夜间自主长任务、广泛邮件和账号插件、完整语音人格、复杂口型、大量动作生成、微信接入、最终四房间到后续版本实现，但 M1 架构不能与这些标准冲突。
